Publishing:
1. Create a free GitHub account at github.com.
2. Create a new PUBLIC repository, e.g. megadhoodh-website.
3. Upload index.html.
4. Repository Settings -> Pages -> Deploy from branch -> main -> /root.
5. GitHub will provide a pages URL.
6. In GoDaddy DNS, connect megadhoodh.in using the GitHub Pages custom-domain instructions.
7. Before publishing, replace the placeholder WhatsApp number 919999999999 in index.html with the actual business WhatsApp number.
