MEGADHOODH + SKY FIBERNET WEBSITE + VISUAL EDITOR

Files:
- index.html: live website
- editor.html: visual editing tool
- megadhoodhlogo.png: Megadhoodh Cable Network logo
- skylogo.png: SKY Fibernet logo

HOW TO USE
1. Upload all four files to the root of your GitHub repository (same folder as index.html).
2. Wait for GitHub Pages to deploy.
3. Open https://megadhoodh.in/editor.html
4. Click Enable click-to-edit, then click text in the preview to edit it.
5. Use the colour controls to change theme colours and upload controls to preview replacement logos.
6. Click Download edited HTML to download the updated index.html.
7. Go to GitHub repository -> Add file -> Upload files. Upload the downloaded index.html and commit changes.
8. GitHub Pages redeploys the site automatically.

IMPORTANT
- This is a free, browser-side visual editor. It does not write directly to GitHub or change the live site by itself.
- Drafts saved in the editor stay in the same browser only.
- Publishing is done by uploading/committing the downloaded index.html to GitHub.
- Anyone who can access editor.html can use the preview editor, but they cannot publish to your GitHub repository unless they have repository access.
- For image replacements, the downloaded HTML embeds the selected logo image as data, so the logo file itself does not need to be uploaded again for that replacement.
